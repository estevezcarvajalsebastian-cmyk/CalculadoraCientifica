
# Calculadora Cientifica - Java Swing

## Descripcion
Aplicacion de escritorio desarrollada en Java
Swing que permite realizar operaciones
aritmeticas, conversiones de temperatura,
raices cuadradas y potencias.

## Funcionalidades

- Suma.
- Resta.
- Multiplicacion.
- Division con validacion de division por cero.
- Conversion Fahrenheit a Celsius.
- Conversion Celsius a Fahrenheit.
- Calculo de raiz cuadrada.
- Calculo de potencias.
- Manejo de errores.

## Tecnologias utilizadas

- Java JDK 26.
- Java Swing.
- Apache NetBeans.
- Programacion Orientada a Objetos (POO).

## Estructura del proyecto

- Calculadora.java
- ConversorTemperatura.java
- RaizCuadradaExponente.java
- Main.java

## Como ejecutar

1. Descargar o clonar el repositorio.
2. Abrir el proyecto en Apache NetBeans.
3. Verificar que Java JDK este configurado.
4. Ejecutar la clase calculadoraapp.Main.
